# Exploring How Task Complexity and User Self-Efficacy Shape AI Agent Design for AI-assisted Translation

**Jisu Kim · Uran Oh**  
**CHI 2026 Extended Abstracts · Published · Article 270**

[ACM Digital Library](https://dl.acm.org/doi/full/10.1145/3772363.3798781) · [DOI](https://doi.org/10.1145/3772363.3798781)

## Overview

This study examines how task complexity and user self-efficacy influence experiences with AI-assisted translation. We conducted a within-subjects study with **20 participants**, comparing a conversational large language model (LLM) interface with a structured AI-agent pipeline across three levels of task complexity.

## Key findings

- The conversational LLM was generally preferred over the evaluated agent pipeline in satisfaction, perceived workload, and interaction efficiency.
- Usability differences widened as translation task complexity increased, with potential outcome-related trade-offs at medium complexity.
- Participants with higher self-efficacy were more sensitive to reduced perceived control in the agent pipeline.

These findings suggest design opportunities for AI-assisted workflows that separate user intent from content generation and support adaptive levels of automation while preserving user agency. Results reflect the particular pipeline and translation tasks evaluated rather than all AI agents.
